# Local-grid project imports

Accept easting/northing collars without latitude/longitude. Keep traces and OBJ meshes in the supplied local frame. Use the shared Baselode PlanView on the landing page; release that library export before the frontend release. The older-library fallback explains the missing plan-view capability without inventing a projection.

Folder readers use canonical files directly within the selected directory. Child projects are excluded. Read and parse failures appear in the sidebar, and the loading state starts before reading files. JavaScript Parquet codecs preserve the existing desktop security policy; no filesystem scope or execution-policy expansion is required.

Verify synthetic local/geographic coordinates, empty and mixed-coordinate files, nested folders, corrupt files, cancellation, loading/error state transitions, and compressed Parquet with WebAssembly unavailable. Build against the shared library containing PlanView. Confidential datasets remain outside this repository.
